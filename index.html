The doctrine

01
Proof-of-Stake reputation. Vouching costs stake. Vouch for malware and get slashed. Decentralized trust needs mathematical consequences, not goodwill.
02
Trust-tiered gateway. Anyone uploads to the Free Commons — but the discovery API agents query defaults to filtering un-staked, unverified noise.
03
First-party firewall. Our own skills play by the same rules, pay the same fees, earn reputation via the same telemetry as a stranger's. No thumb on the scale.
04
Built for agents, not just humans. The endgame is runtime skill acquisition: an agent hits a failing task, queries the Foundry, downloads a Rare skill, pays a micro-transaction. A machine-readable trust graph.
